# Order sync and appearance — October 18, 2026

Wix read-only verification found orders 27528 and 27529 approved, NOT_PAID and NOT_FULFILLED. The legacy paid-only query omitted them. The new import combines recent history with all outstanding approved orders, including offline, partial and pending payments. It follows cursor pages, deduplicates IDs, preserves Wix payment/fulfillment status, and fails on an incomplete/invalid paginated response. Existing completed delivery work stays completed. Cancellation, rejection, fully refunded and declined payment orders are not added by the outstanding query. No Wix order is modified.

Payment status is shown in the queue for unpaid/partial/pending orders. Sync remains an explicit import action; it does not charge, mark paid, fulfill or dispatch. Old approved orders still open in Wix can now appear, with their original dates visible. The existing queue sorts by source creation date.
